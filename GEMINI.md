# GEMINI.md

## Project Overview

This is a portfolio website built with Angular. It uses Tailwind CSS for styling and includes the DaisyUI component library. The project is generated with the Angular CLI.

## Building and Running

### Development Server

To run the development server, use the following command:

```bash
ng serve
```

This will start a development server on `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

### Building

To build the project, use the following command:

```bash
ng build
```

The build artifacts will be stored in the `dist/` directory.

### Testing

To run the unit tests, use the following command:

```bash
ng test
```

## Development Conventions

The project uses the standard Angular development conventions. It includes `tailwindcss` for CSS, so it's recommended to follow the Tailwind CSS utility-first approach for styling.
